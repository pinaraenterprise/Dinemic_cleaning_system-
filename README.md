# DYNAMIC CLEANING SYSTEM — Industrial Equipment & Servicing Portal

High-performance static corporate web application for **DYNAMIC CLEANING SYSTEM**, specializing in industrial vacuum cleaners, road sweepers, high-pressure jet cleaners, scrubber driers, and annual maintenance contracts (AMC).

Hosted serverless on **GitHub Pages** with zero runtime dependencies.

---

## 🚀 Core Features

- **Modern Industrial Dark UI**: Engineered with an enterprise aesthetic, high-contrast cyan accents, and mobile-first responsiveness.
- **Complete Machinery Catalog**: Structured breakdowns of wet & dry vacuums, flame-proof extractors, road sweepers, scrubber driers, and 100–2000 Bar jet washers.
- **Interactive WhatsApp Estimation Engine**: Direct form-to-WhatsApp automation enabling potential clients to send formatted equipment inquiries directly to the sales desk.
- **Specification Tables**: Clear equipment capabilities, motor ratings, and price guidance.
- **SEO & Schema Markup**: Pre-configured JSON-LD local business metadata for search engine indexing.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic document structure with localized business schema.
- **CSS3**: Native CSS custom properties (variables), Flexbox, CSS Grid, and hardware-accelerated drawer animations.
- **JavaScript (ES6+)**: Vanilla client-side controller handling dynamic DOM rendering, event delegation, and URI query construction for WhatsApp deep-linking.
